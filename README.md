<h1 align="center">Missão Aurora - Simulador de pouso</h1>
<h2>📑 Sobre o projeto</h2>
<p>O projeto é um simulador de pouso em Marte, sendo desenvolvido ao máximo de acordo com a realidade, tendo sido usado conceitos da física. Tudo foi desenvolvido com a linguagem Python, utilizando a biblioteca CustomTkinter como interface gráfica. É calculado durante a simulação a velocidade, consumo de combustível, aceleração, frenagem com retrofoguete e com paraquedas e o tempo de chegada até ao solo. O objetivo é pousar os 6 módulos em segurança, sendo considerado como um pouso seguro o módulo chegar ao solo com uma velocidade a baixo ou igual a 1 m/s; se o pouso for com velocidade acima de 1 m/s e até 3 m/s o módulo sofrerá impacto; e, se o módulo pousar com uma velocidade acima de 3 m/s resultará no danificamento da carga.</p>
<h2>⚙️ Instruções de uso</h2>
<p>Baixe o executável e execute no seu sistema operacional, caso o antivírus bloqueie, é devido ao fato da certificação de desenvolvimento da Microsoft não estar presente, no entanto, apenas prossiga que o programa irá iniciar normalmente. Caso queira rodar no seu IDE, baixe os arquivos do repositório e rode o arquivo "main.py". No segundo método de execução é necessário importar as bibliotecas, então preste atenção nisso para um bom funcionamento do programa.</p>
